# Discord бот сообщества

Node.js 20+, discord.js 14. Бот создаёт голосовые комнаты с отдельным чатом управления, публикует поиск группы, принимает запросы помощи и отправляет объявления с упоминанием роли.

## Запуск

1. Создайте приложение и бота в [Discord Developer Portal](https://discord.com/developers/applications). Пригласите его с правами `bot` и `applications.commands`.
2. Выдайте боту права **Manage Channels**, **Manage Roles**, **Move Members**, **Send Messages**, **View Channels** и **Embed Links**. Роль бота должна стоять выше ролей, которыми он управляет.
3. В этой папке выполните `npm install`, скопируйте `.env.example` в `.env` и заполните токен, ID приложения и сервера. Токен вписывается после `DISCORD_TOKEN=` без кавычек и пробелов. Никому не отправляйте токен.
4. Запустите `npm start`. На сервере выполните `/настройка`, указав категорию комнат, канал поиска, канал запросов и роль модераторов. Лобби необязательно.

## Команды

- `/комната название слоты` — голосовая комната с панелью управления прямо в её чате. Вход в настроенное лобби тоже создаёт комнату. Пустая комната удаляется автоматически после выхода участников.
- `/сбор название места роль` — объявление с кнопками присоединения и выхода в канале поиска.
- `/помощь-панель` — панель с кнопками «Задать вопрос», «Пожаловаться», «Позвать модератора». Ответы поступают в настроенный канал.
- `/тег роль сообщение` — объявление с текстом, введённым при запуске команды, и упоминанием выбранной роли. Для фактического уведомления роль должна быть упоминаемой либо у автора должно быть право упоминания всех ролей.

Параметры и активные комнаты сохраняются в `data/state.json`. Не публикуйте `.env` и эту папку с данными.

Готовая графика лежит в `assets/`: `help-banner.png` автоматически появляется на панели помощи, `bot-icon.png` можно загрузить как аватар бота в Discord Developer Portal → Bot → Icon.

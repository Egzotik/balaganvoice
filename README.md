# Balagan Voice — Discord-бот

Бот создаёт временные голосовые комнаты, показывает панель управления **в чате самого войса**, публикует объявления поиска группы и принимает запросы помощи.

## Запуск

Нужен Node.js 20 или новее. Создайте бота в [Discord Developer Portal](https://discord.com/developers/applications) и пригласите его с областями `bot` и `applications.commands`. Выдайте права на управление каналами, перемещение участников, отправку и чтение сообщений, встраивание ссылок и установку статуса голосового канала.

1. Выполните `npm ci` в папке бота.
2. Скопируйте `.env.example` в `.env` и заполните `DISCORD_TOKEN`, `DISCORD_CLIENT_ID` и `DISCORD_GUILD_ID`. Токен храните только локально или в секретах хостинга.
3. Запустите `npm start`.
4. Один раз выполните `/настройка` на сервере. Команда требует права **Управлять сервером**.

## Slash-команды

| Команда | Параметры | Действие |
| --- | --- | --- |
| `/настройка` | `категория`, `поиск`, `запросы`, `модераторы` — обязательные; `лобби` — необязательный | Сохраняет категорию временных комнат, каналы поиска и помощи, роль модераторов и входной войс. Если лобби не указано, бот создаёт канал «➕ Создать комнату» при следующем запуске. |
| `/комната` | `название` — обязательный; `слоты` — необязательный | Создаёт временный войс с панелью в его чате. По умолчанию 3 места. Если автор уже в войсе, бот переносит его в новую комнату. |
| `/сбор` | `название`, `места` — обязательные; `роль` — необязательная | Публикует набор в канале поиска. Если автор находится в войсе, список участников объявления берётся из этого войса и обновляется при входе и выходе. |
| `/помощь-панель` | без параметров | Публикует панель «Задать вопрос», «Пожаловаться», «Позвать модератора». Требует права **Управлять сервером**. |
| `/тег` | `роль`, `сообщение` — обязательные | Отправляет объявление с упоминанием выбранной роли. Для уведомления роль должна быть упоминаемой либо автору нужно право упоминать все роли. |

**Без команды:** вход в «➕ Создать комнату» создаёт временный войс и переносит участника туда. Комната удаляется, когда из неё выходит последний участник. Постоянные войсы остаются выше входного канала; временные создаются ниже него.

## Кнопки в чате временного войса

«Написать в поиск-пати» публикует карточку с текущими участниками войса, свободными местами и ссылкой для входа. «Добавить/Изменить комментарий» устанавливает **статус голосового канала**. «Поднять команду» перемещает временный войс сразу под «➕ Создать комнату», не затрагивая постоянные войсы. Остальные кнопки меняют владельца, доступ, название, лимит мест и право говорить.

Настройки, активные комнаты и объявления сохраняются в `data/state.json`. Для постоянного хостинга храните этот файл на постоянном диске. В `assets/` лежат баннеры по мотивам ROB RUN: `robrun-help.png` для панели помощи, `robrun-squad.png` для `/сбор` и `robrun-announcement.png` для `/тег`. `bot-icon.png` можно загрузить как аватар в Discord Developer Portal.
